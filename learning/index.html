CairnKV · 存储引擎前置知识

课程地图

对应 docs/learning-path.md §2.1 / §2.2 / §2.4（Go 部分不在本课程内）

每课 20–30 分钟每 3–4 课一次混合复习路线随学习记录动态调整

A · 存储与文件系统（M0–M1 之前）

  1. 一次写入何时才算"落地"：write / fsync / rename / 目录 fsync
  2. fsync 到底刷到哪：macOS F_FULLFSYNC、fdatasync、O_DIRECT（自测 2）
  3. fsync 失败之后：fsyncgate 与毒化状态机（V-04）
  4. 半截写：扇区原子性、torn write 与 CRC（自测 4）
  5. mmap 的代价，以及为什么第一期不用（自测 3、5）
  6. 文件系统不生而平等：精读 Pillai OSDI'14 的属性表

B · LSM 核心（M1–M3）

  1. LSM 全景：为什么把随机写变成顺序追加
  2. 手工解码一条 LevelDB WAL 记录
  3. 组提交与确认点
  4. skiplist + arena 内存表
  5. internal key、seqnum 与全序比较（V-01）
  6. 恢复：logSeqNum 的重建（V-08）
  7. SSTable 数据块：前缀压缩与 restart points
  8. Bloom 过滤器与误判率
  9. leveled vs tiered：WA / RA / SA 与 RUM
  10. 墓碑与回收的两个条件

C · 测试方法论（M1–M5）

  1. vfs 故障注入、模型对拍、蜕变测试：各防哪类缺陷

速查

  • 持久化与崩溃一致性
  • OSTEP 持久化重读计划（A 阶段的主线阅读，课程穿插其中作检查点）
