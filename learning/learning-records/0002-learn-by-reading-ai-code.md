# 学习方式改为「先上课、AI 实现、读代码」，不再亲手实现

用户决定 CairnKV 的全部代码由 AI 编写，自己只读代码、理解原理（2026-10-31）。今后的流程是：每个模块开工前先上对应的课，AI 实现后附讲解稿，用户按讲解稿里的阅读路线读代码。

**Implications**：
- 课后练习从「写实现」改为三种：读刚实现的代码、回答讲解稿里的自测问题、手工解码 `docs/file-format.md` 中的样例。
- 课程顺序跟随实现顺序：M0 vfs 之前上第 2 课，M1 之前完成第 3、4、7–12 课，详见仓库 `CLAUDE.md` 第 4 节。
- 用户读代码的能力没有经过评估，前几次讲解稿后要观察用户能否顺着阅读路线读下去，再据此调整讲解深度。

**Evidence**：用户原话：「A 档也你来写吧，我读代码大概了解一下原理就行了」「每次实现一个模块之前先进行一些理论学习……就用 teach skill」。见 [[MISSION.md]]。
